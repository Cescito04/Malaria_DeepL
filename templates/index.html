🔬 Comment ça fonctionne ?

Notre modèle de deep learning utilise une architecture CNN (Convolutional Neural Network) de type {{ metrics.get('model_name', 'Mini-VGG') }} pour analyser les images de cellules sanguines. Le modèle a été entraîné sur un large dataset d'images de cellules parasitées et non parasitées. Lors de l'analyse, le modèle examine les caractéristiques visuelles de l'image et détermine avec une précision de {{ "%.2f"|format(metrics.get('test_accuracy', 0.9509) * 100) }}% si la cellule est infectée par le paludisme ou non. Le processus d'analyse prend généralement moins de 2 secondes.
